FAQ

Common questions

Are these codes real - will they work on actual websites?

Yes. NecAuth uses the standard TOTP algorithm (RFC 6238) with the same secret key a site gave you, so the code matches what that site expects - identical to Google Authenticator for the same key and time.

Where is my secret key stored?

Only in this browser, in local storage on your own device. It is never sent to any server. Clearing browser data for this site removes the vault, so keep a JSON backup from the export button.

My codes are being rejected. What is wrong?

In almost every case it is the device clock. Enable automatic date and time in your phone settings, re-check with the Device Time Check tool above, and make sure the secret key was copied without missing characters.

Can I add this login system to my own app?

Yes - the Generate New Secret tool creates the same enrollment data a backend needs. For a complete server-side integration with user accounts, see the Buy Info section and contact the developer on Telegram.
