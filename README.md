# NecAuth

Clean two-factor authenticator by NECXY DEVELOPER.
Enter a 2FA secret key, press Generate, get a real TOTP code.

Install as an app (PWA): open the live site on your phone and tap the
download icon in the header, on the right side. On Android Chrome
this opens the install prompt; on iPhone use Share > Add to Home Screen.
The installed app works offline. This is a PWA, not an APK file.
